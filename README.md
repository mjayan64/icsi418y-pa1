# My Task List Manager
## Author
Mehul Jayan
## Description
My Task List Manager is a webpage created with HTML, CSS, and JavaScript. Users can add tasks with a priority of low, medium, or high. The tasks will be displayed in order of priority, and users can mark tasks as complete and delete teasks.

## How to Run
1. Download or clone repository
2. Open repository
3. Open index.html in browser
